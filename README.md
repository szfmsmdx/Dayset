# Dayset

Dayset 是一款面向 Windows 的个人待办应用。随手记下要做的事，按日期安排，再逐件完成。界面保持简洁，任务保存在本机，无需账号或网络连接。

## 下载

在 [GitHub Releases](https://github.com/szfmsmdx/Dayset/releases) 下载已发布的 Windows 版本：

- `Dayset_<版本号>_x64-setup.exe`：安装版，提供开始菜单入口和卸载程序。
- `Dayset_<版本号>_x64.exe`：直接运行的 EXE，无需安装。任务数据仍保存在本机应用数据目录中，不随 EXE 移动；Windows 系统提醒需要安装版。

支持 Windows 10/11 x64，需要 WebView2 Runtime。当前构建尚未进行代码签名，Windows 可能显示“未知发布者”提示。请以 Releases 页面上的版本号和附件为准。

## 如何使用

1. 在 **今天**、**待安排**、**计划**之间切换。今天显示今天和逾期的任务；待安排放尚未安排日期的任务；计划显示所有已安排日期的任务。
2. 在底部输入任务并按 Enter 添加。在今天添加的任务默认安排到今天；在计划添加的任务默认安排到明天；在待安排添加的任务不设日期。
3. 点击任务名称展开详情，可修改名称、日期、时间、重复频率、结束方式、提前提醒时间和备注。支持每天、每周、每月、每年重复；默认持续重复，也可设结束日期或总次数。完成当前任务后会安排下一次；如果晚完成，会跳过已错过的周期。改动会保存到本机；点击 **完成设置** 收起详情。
4. 点击底部输入栏时，会在上方弹出任务设置：父任务可留空，也可选择任意未完成任务；日期、时间和提醒可在创建时填写。选中父任务后日期会先沿用其日期，仍可修改。点击外部或点“收起”可关闭面板，也可向下拖动把手收起。已有任务可用左侧点状手柄拖到另一任务下面，拖到列表顶部可移回顶层；层级可以继续嵌套。完成上级前，必须先完成它的所有层级下级任务。
5. 在任务详情的 **标签** 一栏输入标签并点击 **添加**。同名标签可在不同任务间复用；任务栏右侧可按标签筛选。点击标签旁的 `×` 可将它从当前任务移除。
6. 点击任务左侧的方框可标记完成或恢复。已完成的任务仍留在原列表中，以灰色删除线显示。删除任务可在详情底部操作；完成、删除或调整日期后，可在短时间内点击 **撤销**。
7. 点击右上角齿轮进入设置页，可管理通知测试和登录启动选项；点击 **返回任务** 或按 `Esc` 返回。

窗口顶部可拖动，边缘可调整大小。点击 `—` 会最小化到任务栏；点击 `×` 会隐藏到系统托盘，Dayset 继续运行。点击托盘图标可重新打开；在托盘菜单中选择 **退出 Dayset** 才会结束程序。

## 当前功能边界

- Windows 客户端使用本机 SQLite 保存任务；目前没有账号、跨设备同步或数据导出功能。
- 最新的 `v0.1.3` 安装版支持重复任务，并可在 Dayset 运行时发送 Windows 系统通知，隐藏到托盘后也会继续检查；明确退出程序后不会提醒。浏览器预览和直接运行的 EXE 不提供可靠的 Windows 系统提醒。
- [网页原型](prototype/README.md)和开发用浏览器预览各自使用独立的浏览器本地存储，不与 Windows 客户端共享任务。
