# Dayset 网页原型

双击 [index.html](index.html) 可在普通浏览器中打开网页版；宽屏是双栏布局，窄屏会收成小组件。Windows 上也可以双击 [open-widget.cmd](open-widget.cmd)，用 Edge 的独立小窗口体验。无需安装依赖或启动服务器。

- “今天”“收件箱”“计划”可直接切换；宽屏还会显示“已完成”标签。小窗口的“已完成”和“重置示例任务”在右上角菜单里。
- 在底部输入框写任务并按 Enter。今天新增的任务安排到今天，收件箱新增的任务不设日期，计划中新增的任务安排到明天。
- 点击任务可展开日期、具体时间、提前提醒、备注和删除操作；点击左侧圆圈可完成任务。完成、调整日期或删除后，可在短时间内撤销。

任务只保存在当前浏览器的本地存储中，不连接账号或服务器。提醒选项会显示预计提醒时间，但原型**不会发送系统通知**。同一页面会按窗口宽度切换网页与小组件布局，方便我们先验证操作和视觉方向。

界面使用了少量 [Lucide](https://github.com/lucide-icons/lucide) 图标，许可见 [LUCIDE-LICENSE.txt](third-party/LUCIDE-LICENSE.txt)。
