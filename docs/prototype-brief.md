# Dayset · Windows 原型草案

状态：讨论稿。这里定义操作与页面，不决定客户端框架或服务器实现。

## 目标

让个人用户快速记下要做的事，清楚看到今天要处理什么，完成后得到安静、明确的反馈。优先保证添加和完成足够顺手；未来跨端同步不改变这套基本操作。

## 第一轮要验证的操作

1. 输入一句话并按 Enter，任务立即进入收件箱。
2. 将收件箱中的任务安排到今天或指定日期。
3. 在今天的列表里单击勾选完成，并且能撤销误操作。
4. 将没做完的任务移到明天，或直接修改日期。

```text
│              │ ○ 处理一件重要的事                       ⋯   │

│              │ ✓ 已完成的事情                           撤销 │

```

点击任务后，右侧可展开简洁的详情区：标题、日期、备注、删除。默认保持列表完整可见。

## 本轮边界

- 保留收件箱、今天、计划、已完成四个视图；暂不引入项目层级、标签、优先级、统计或习惯打卡。
- 快捷键唤起全局快速添加、系统提醒、离线与同步方式，先作为待验证需求，不在视觉草案中预设实现。
- 原型使用示例任务，不接真实账号或服务器。

## 下一轮验证

做一个可点击的低保真原型，实际走一遍“想到一件事 → 记下 → 安排日期 → 完成或延期”。重点检查主界面是否过于拥挤，以及新增任务能否不用鼠标完成。
