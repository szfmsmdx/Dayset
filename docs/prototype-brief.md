# Dayset · 响应式网页原型

状态：可体验的网页原型。这里验证操作与尺寸，不决定正式客户端框架。

## 目标

在浏览器中快速看到今天要做什么，添加和完成任务。窄屏保持小组件式单栏；宽屏展开为轻量双栏，左侧看日期与进度，右侧处理任务。

## 当前原型

```text
┌──────────────────────────────────┐
│ Dayset                       ··· │
│ 10 月 15 日 星期四                │
│ 今天                        2 件 │
│ 今天      收件箱      计划         │
│                                  │
│ ○ 写下今天最重要的一件事       › │
│ ○ 给朋友回一条消息             › │
│                                  │
│ ＋ 添加一件要做的事…           ↵ │
└──────────────────────────────────┘
```

点击任务时，日期、具体时间、提前提醒、备注和删除操作在该任务下方展开。宽屏通过标签进入“已完成”，小窗口通过右上角菜单进入；菜单里也可重置示例任务。

视觉上以浅蓝为主色，今天视图用一个小进度环反馈完成情况，任务时间用轻量标签展示。窄屏展开任务后顶部区域收紧，让日期和提醒设置更容易看到；宽屏保留完整双栏布局。

## 要验证的流程

1. 在“今天”直接输入并按 Enter，新任务立即出现在今天。
2. 在“收件箱”记录尚未安排日期的任务，随后点击任务安排到今天或明天。
3. 勾选任务完成，在短时间内撤销；也能从“已完成”恢复。
4. 将没做完的任务改到明天，或安排到某天的具体时间，再选准时或提前提醒。

任务和修改只保存在当前浏览器。原型会计算预计提醒时间，但不发送系统通知；正式客户端的通知和服务器同步仍待后续决定。
